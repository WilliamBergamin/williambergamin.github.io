# Dynamic Resume

## What

This Dynamic Resume is a personal website that is generated dynamically from a JSON object that contains resume information. It can easily be deployed to GitHub Pages.

## Why

Software developers are known to be lazy. This is why I have made this tool. With very little effort I can update the website.

## Who should use it

This project was made for me, I am not expecting anyone to use it. But if you want, go ahead. All you need to do is update the resume.js file and change the links to your GitHub and LinkedIn.
